# learn-something
wow

我想學：養成閱讀習慣，增加自己的詞彙量。

我以前卡在：喜歡閱讀但沒有培養成習慣，懶得去買新書和借書。讀了文章但沒有把學到的詞應用在生活中。

我現在的程度，以及我怎麼測的：與人交談時常以「然後」作為連接詞，想表達想法卻不知道如何敘述，偶爾會詞窮。

5週後我要做到：與人交談時能快速組織好通順且清晰的句子，將學習到的詞彙記下，並運用在日常對話與文章書寫上。

我練習的場景、時間和每週次數：通勤時間，每週至少三天，一天大約兩小時。

那個時候我有空的感官：聽、看。

我的產品會怎麼幫我：收集不同類型的文章讓我閱讀與聆聽，列出較難的字、詞做解釋和例句讓我學習，並將學習過的內容做成題庫供我複習。
